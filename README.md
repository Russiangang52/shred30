# SHRED·30 — персональный план похудения на 30 дней

Тёмный одностраничник в стиле Nike Training Club (чёрный фон + неоновый лайм): рацион на 4 недели, план тренировок недели и интерактивный трекер прогресса.

**Цель программы:** 79,5 → 74,5 кг (−5 кг) за 30 дней.

## Что внутри

- **Цель и цифры** — расчёт по формуле Миффлина — Сан Жеора: BMR 1821 ккал, расход ≈ 2800 ккал, рацион **2150 ккал/день** (дефицит ≈ 650 ккал / 23%), БЖУ 140/70/240 г, прогноз веса по неделям.
- **Питание** — меню на 4 недели × 7 дней × 3 приёма пищи с граммовками и калориями, таблица замен продуктов и список покупок.
- **Тренировки недели** — 2–3 тренировки в зале (фулбади A/B/C) + 1 хоккей: упражнения, подходы, отдых, финишеры, прогрессия на 4 недели.
- **Правила** — 10 правил, без которых план не работает (вода, сон, шаги, взвешивания, свободный приём пищи…).
- **Трекер прогресса** — сетка чек-инов на 30 дней, серия подряд, запись веса с графиком против планового прогноза. Данные хранятся в `localStorage` браузера.

## Стек

- Next.js 16 (App Router) + TypeScript
- Tailwind CSS 4 + shadcn/ui
- framer-motion, recharts, lucide-react

## Запуск

```bash
# bun
bun install
bun run dev        # http://localhost:3000

# или npm
npm install
npm run dev
```

Продакшен-сборка:

```bash
bun run build
bun run start      # standalone-сервер на .next/standalone/server.js
```

## Как перенастроить под себя

Все цифры и планы лежат в трёх файлах — правятся без знаний фреймворка:

| Файл | Что внутри |
| --- | --- |
| `src/lib/profile.ts` | Возраст, рост, вес, калории, БЖУ, прогноз, правила |
| `src/lib/nutrition.ts` | Меню на 4 недели, замены продуктов, список покупок |
| `src/lib/training.ts` | Недельный план тренировок, прогрессия, правила |

Данные трекера не отправляются никуда: всё живёт в `localStorage` под ключом `shred30-progress-v1`.

## Важно

Программа рассчитана на конкретного человека (мужчина, 17 лет, 177 см, 79,5 кг). Это не медицинская рекомендация: перед дефицитом калорий стоит посоветоваться с врачом, особенно в несовершеннолетнем возрасте.
